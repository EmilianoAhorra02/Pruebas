Proyecto Pruebas

Este es un repositorio de práctica donde se implementa el flujo de trabajo **Git Flow** para controlar versiones, organizar el desarrollo y realizar entregas ordenadas.

---

🚀 ¿Qué contiene este proyecto?

Este proyecto incluye ejemplos básicos de HTML como parte de las pruebas con ramas en Git Flow:

- `hola_word.html`: muestra un mensaje de bienvenida.
- `Sueños_Magicos.html`: segundo ejemplo agregado como una nueva funcionalidad.

---

📄 Estructura de trabajo (Git Flow)

Se sigue el modelo de ramas **Git Flow**, que organiza el proyecto en:

- `Main` (producción): rama estable donde se publican las versiones finales.
- `develop`: rama de desarrollo principal.
- `feature/*`: ramas donde se desarrolla una funcionalidad.
- `release/*`: ramas para preparar una versión antes de publicarla.
- `hotfix/*`: para corregir errores urgentes directamente en producción (aún no usado en este proyecto).
